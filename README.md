# YEC Management — website

Static multi-page site (plain HTML/CSS/JS). Host anywhere, including **GitHub Pages**.

## Pages
index.html · about.html · what-we-do.html · clients.html · credentials.html · social-value.html · careers.html · contact.html

## Assets
- assets/css/styles.css — all styling
- assets/js/main.js — nav, expanding services/clients/credentials, company-profile PDF
- assets/img/ — photography, YEC logo, Armed Forces Covenant mark, favicon

## Deploy to GitHub Pages
1. Upload the contents of this folder to your repo (keep the structure).
2. Settings → Pages → Deploy from a branch → main / root.
3. Publishes at https://<username>.github.io/<repo>/. The .nojekyll file keeps the assets/ folder intact.

## Editing
Page text is in each .html file. The services, client list and credentials are arrays at the
top of assets/js/main.js — edit once to update every page.

## Armed Forces Covenant mark
assets/img/afc_mark.png is the official positive brand mark, shown on white panels per the
Armed Forces Covenant brand guidelines (YEC is a signatory, pledge dated 12 March 2026).
